# -Yutnori
윷놀이 "전국일주"(Yutnori "Nationwide Tour")

이 게임은 한국의 전통놀이인 윷놀이와 대한민국의 전국 유명 명소를 둘러보는 가상투어를 결합하여 한국을 소개하는 목적으로 제작하는 게임입니다.
This game is being produced for the purpose of introducing Korea by combining the traditional Korean game of Yutnori with a virtual tour of famous landmarks across South Korea.
